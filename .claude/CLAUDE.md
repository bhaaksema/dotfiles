## Code
- **Suppressions:** Never add new type or lint ignore directives, instead fix the root cause. Only suppress when genuinely unavoidable.
- **Comments:** Few and terse, only for non-obvious reasoning. Never let your instructions or task context seep into them.

## Git
- **Commits:** Scoped Commits format `<scope>: <description>`, where scope is the subsystem/area the commit touches and description is a one-line summary. The commit message is exactly this single line and ends there. If the commit covers multiple scopes, use a more general scope instead.

## Claims
- **Verification:** Every statement is checked against current documentation or the actual environment before it is made.
